# Body of Work — Arman Mahmoudi

Interactive catalog of Arman Mahmoudi's paintings and drawings, built in
the format of work.jamesdaly.art (dark mode): announcement bar, lime
tagline block, giant name heading, "Where the work lives" with an animated
dotted globe, timeline, filters, a 3-column works grid, and a work detail
overlay.

- Dark mode, neo-grotesque sans-serif throughout
- Only the artist's own data: his 13 photos and his resume (one exhibition,
  Tehran 2026). No invented titles, dimensions, prices or collector places.
- The globe is a self-contained canvas dotted world map (land dots sampled
  from world-atlas land-110m). It auto-rotates, drags, pauses, zooms, and
  carries one real marker: the 2026 Tehran exhibition.
- Images are hosted on armanmahmoudi.ir/gallery/ and referenced from there,
  so this repository stays text-only (HTML, CSS, JS)
- Static site, served free by GitHub Pages

Live: https://aaarmaan.github.io/work/
