# Body of Work — Arman Mahmoudi

Separate interactive catalog of Arman Mahmoudi's paintings and drawings,
modelled on the "Body of Work" catalog format: a filterable grid of works,
a detail view with previous/next navigation, and the CV.

- Dark mode, Times serif, gold accents — same palette as armanmahmoudi.ir
- Works data (series, years) and CV taken from armanmahmoudi.ir
- Images are hosted on armanmahmoudi.ir/gallery/ and referenced from there,
  so this repository stays text-only (HTML, CSS, JS)
- Static site, served free by GitHub Pages

Live: https://aaarmaan.github.io/work/
